# フロントエンドUI・UX・URL連携仕様書

## 1. 画面モードとURLクエリパラメータ仕様

本アプリは GitHub Pages 上で単体動作する3D企業関係ネットワークビューアであり、通常表示モードに加えてコンパクトなスリム表示モード（`?embed=1`）や、任意のURLクエリによる初期状態指定・共有に対応する。すべてのパラメータは任意とし、未指定時は安全なデフォルト値で動作する。

### 共有URLの例

```text
# 通常モード（主要ハブ180社で起動）
https://asoka501.github.io/Git_stock_networkmap/

# スリム表示＋特定銘柄へフォーカス＋保有銘柄ハイライト
https://asoka501.github.io/Git_stock_networkmap/?embed=1&holdings=7203,6758,8035&focus=7203&hops=1
```

### URLクエリパラメータ一覧（[src/embedConfig.ts](../src/embedConfig.ts)）

| パラメータ | 例 | 動作 |
| --- | --- | --- |
| `embed` | `1` / `true` | スリム表示モードを有効化（ヘッダー最小化、左フィルタパネル初期折りたたみ、JSON読込ボタン非表示） |
| `focus` | `7203` | 起動時に指定の証券コードへ自動フォーカス＆詳細インスペクタ表示 |
| `holdings` | `7203,6758,8035` | カンマ区切りの保有銘柄コードをゴールド強調表示し、保有銘柄周辺モードの基準にする |
| `hops` | `1` / `2` | `focus` または `holdings` 指定時に表示する隣接ホップ数（既定：`1`） |
| `mode` | `core` / `holdings` / `all` | 初期表示スコープ（未指定時：`holdings` があれば `holdings` 周辺、なければ `core` 主要ハブ180社） |
| `metric` | `marketCap` / `capital` | 初期のノードサイズ基準（既定：`marketCap`） |
| `minValue` | `0` 〜 `90` | 関係値スライダーの初期下限（既定：`0`） |
| `kind` | `主要顧客・供給,政策保有株式` | 表示する関係種別の初期絞り込み |
| `source` | `all` / `table` | 出典フィルタの初期値（`table` 指定時は定型表由来エッジのみ表示） |
| `rotate` | `0` / `1` | 自動回転の初期ON/OFF（既定：`1`、ただし `focus` 指定時は `0`） |
| `data` | `https://...json` | 任意のネットワークJSON URLを読み込むデバッグ・差し替え用フック（HTTPS限定） |

## 2. レイアウトと操作UI

**原則：「画面の大部分を3Dキャンバスに開放しつつ、全上場3,856社への検索・絞り込み・深掘り操作に1クリックで届く」**

### 2.1 通常モード vs スリムモード（`?embed=1`）

| UI要素 | 通常モード | スリムモード（`?embed=1`） |
| --- | --- | --- |
| 左上タイトルヘッダー | タイトル＋収録件数バッジ表示 | **非表示**（スペースを3Dキャンバスへ開放） |
| 上部フローティングバー | 全社検索・フィルタ開閉・表示範囲・回転・全体リセット・全画面・共有コード・JSON読込 | **コンパクトなピル型バー**（全社検索・フィルタ開閉・表示範囲・全体リセット・全画面） |
| 左コントロールパネル | 画面幅 `md` 以上で常時表示 | **初期折りたたみ**（フィルタボタンで半透明ドロワー開閉） |
| 右詳細インスペクタ | ノードクリック時にスライド表示（企業概要・時価総額・有報抜粋・ミニロゴ付き関係企業一覧） | 同左（狭い画面幅でも重なりを回避） |
| JSON読込モーダル | ボタン表示（ローカル検証・手動JSON差し替え用） | 非表示 |

### 2.2 主要UX機能（実装済み）
1. **表示スコープ切替（コアハブ / 保有銘柄周辺 / 選択銘柄の1〜2ホップ / 全社）**
   - 起動時は主要ハブ180社（`core.json`）で軽快に表示し、検索・選択・ホップ拡張時に全上場3,791社データ（`network.json`）から必要な部分グラフを即座に展開する。
2. **関係種別フィルタ（全6種）＆出典フィルタ**
   - `政策保有株式` / `大株主` / `主要顧客・供給` / `資本・業務提携` / `共同開発・協業` / `供給網・リスク` をチップボタンでON/OFF。
   - 出典フィルタ（`すべて` / `定型表のみ`）により、定型表の定量関係のみに絞った閲覧も可能。なお定型表・本文共起のいずれもLLM不要の自動パイプラインで生成される。
3. **インスペクタ関係企業一覧のミニロゴ表示**（[src/main.ts](../src/main.ts) / [src/logoLoader.ts](../src/logoLoader.ts)）
   - 選択企業の関係企業リストでは、セクター色ドット（`●`）と企業名の間に `20×20px` の企業ミニロゴを `loading="lazy"` で差し込み、視認性と一覧性を高める。未取得ロゴは自動で非表示フォールバックしレイアウト崩れを起こさない。
4. **芋づる式探索＆ショートカット**
   - 詳細パネルに「この銘柄周辺に絞る」「さらに1ホップ広げる」ボタンを配置。
   - キーボードショートカット：`/`（検索フォーカス）、`R`（全体表示リセット）、`Esc`（選択解除・モーダル閉じ）。
   - `ResizeObserver` によるコンテナリサイズ追従、ツールチップの画面端クランプ制御、全画面表示ボタンに対応。

### ズーム連動カラー切替
- **ズームアウト（俯瞰）時**：11大分類の基本色で描画し、産業クラスタ全体をひと目で把握可能にする。
- **ズームイン時**：カメラ距離がしきい値を下回ると、各ノードの `subSector`（JPX 33業種）に応じた同系近似色（例：金融内で銀行・証券・保険を赤系濃淡で分離）へ自動で切り替わり、画面下部に「`33業種 近似色`」バッジを表示する。
- **表記揺れガード**：EDINET側の変種表記（`倉庫・運輸関連`、`外国法人・組合`、旧表記 `消費・医薬`）はフロント・バックエンド双方で正規化し、未分類漏れを防ぐ。

## 4. 全上場規模（3,791社・27,391本）の高速描画＆ロゴ多段フォールバック

1. **段階データ読込＆ハイブリッド主要ハブ選定**
   - 起動時は `meta.json`（0.2KB）・`index.json`（888KB）・`core.json`（425KB・時価総額上位120社＋構造ハブ上位60社の計180社）を並列取得して即座に3D描画する。
   - コア外銘柄の検索や全表示切替時に `network.json`（8.2MB）を遅延取得・メモリキャッシュし、ノード選択時のみ該当証券コード先頭1桁の `details/{1-9}.json` を取得する。
2. **全表示切替時の自動中規模フィルタ＆見た目を妥協しない軽量化**
   - 「全表示」へ切り替えた際は、関係値フィルタを自動的に**中規模（`45` 以上）**へ設定し、エッジ数を約 1/9（約2,700〜3,100本）へ整理するとともに孤立ノードを非表示化する（手動で `0` へ戻せば全エッジ閲覧可能。主要ハブへ戻すと元の値へ自動復帰）。
   - フィルタ・スライダー変更時は既存ノードの3D座標（`x, y, z`）をキャッシュ引き継ぎし、再爆発によるカタツキを防止する。
   - 大規模グラフ（400社超）では `warmupTicks` / `cooldownTicks` / `d3AlphaDecay` を最適化し、物理収束＋カメラ静止中は2Dロゴ/ラベルオーバーレイの再描画を完全スキップ（アイドルCPU負荷ゼロ）、大規模ドラッグ中のみ2Dオーバーレイを30fps相当へ間引いて3D描画の60fpsを維持する。
3. **ロゴ取得の多段フォールバック（[src/logoLoader.ts](../src/logoLoader.ts)）**
   - 以下の優先順で自動試行し、成功URLをキャッシュ・全滅時は再試行せず略称イニシャルバッジへ即時フォールバックする：
     1. `node.logo`（既定：`https://logoapi.sh/ticker/{code}.svg`）
     2. `https://logoapi.sh/{domain}`（日本株大手で高ヒット率・無料・トークン不要）
     3. `node.logoFallbacks`（JSON側で個別指定がある場合）
     4. `https://img.logokit.com/{domain}?token={VITE_LOGOKIT_TOKEN}`（トークン設定時）
     5. `https://img.logokit.com/ticker/{code}.T?token={VITE_LOGOKIT_TOKEN}`（トークン設定時）
     6. セクター色＋企業略称イニシャルバッジ
   - **保守上の注意**：LogoKit 等のCDNは `Access-Control-Allow-Origin` を返さない場合があるため、Canvas 2D 描画用の `Image` 要素には `crossOrigin = 'anonymous'` を設定しない設計としている（ピクセル読み出しを行わないため安全）。
